# Jigzzy - Interactive Adventure Map Puzzle (Version : Alpha! )

## Overview
Jigzzy is an interactive web-based puzzle game that transforms images into engaging jigsaw puzzles. Players can interact with puzzle segments, move them around, and rebuild geographical locations, 
offering both entertainment and educational value for geography enthusiasts.

## 🚀 Features
- **Interactive Puzzles**: Transform geographical image into movable puzzle
- **Drag-and-Drop Interface**: Intuitive piece movement and placement
- **Difficulty Levels**: Adjustable piece count and complexity
- **Location Learning**: Educational tool for geography exploration
- **Responsive Design**: Works on both desktop and mobile devices

## 📋 Repository Structure
- `map.html`: Main map visualization component
- `jigzy.html`: Interactive jigsaw puzzle interface
- `js/`: JavaScript files that power the application
- `css/`: Styling and layout files
- `assets/`: Images and other static resources

## 🛠️ Technology Stack
- HTML5
- CSS3
- JavaScript
- Leaflet.js for map rendering
- HTML5 Drag and Drop API for puzzle interaction

## 🚦 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Basic understanding of HTML/CSS/JavaScript (for developers)

### Installation
1. Clone the repository:
```bash
git clone https://github.com/MrslvKlv/Jigzzy.git
```

2. Navigate to the Jigz2 branch:
```bash
git checkout Jigz2
```

3. Open `map.html` in your browser to start using the application.

## 📝 How to Use

### Map View
1. Open `map.html` in your browser
2. Chose any of the pre-selected images 
3. Automatically moving to Puzzle Mode
### Puzzle Mode
1. The selected image will be divided into puzzle pieces
2. Drag and drop pieces to reconstruct the image
3. Once all pieces are correctly placed, you'll receive a completion notification

## ⚙️ Configuration
You can customize various aspects of Jigzzy by modifying parameters in the JavaScript files:

- Puzzle difficulty (number of pieces)
- Map region and zoom level
- Visual styling and effects
